## Summary

This repository contains the complete computational library supporting the paper.
Every number appearing in the paper — mass ratios, relic abundance, self-interaction
cross-sections, gravitational wave peak frequency and SNR, collider event rates — is
generated by running the code in this repository with zero manual adjustment.

The library covers three appendices and five paper sections:

| Component | File(s) | Paper section |
|-----------|---------|---------------|
| Homotopy proof π₂ = ℤ | `homotopy/` | Appendix A |
| BPS profile functions | `homotopy/winding_number.py` | Appendix A, Fig. 1 |
| GMO mass operator + Dark Higgs Triplet | `spectrum/gmo_formula.py` | Section 3 |
| Weight diagram | `spectrum/dark_octet.py` | Section 3, Fig. 2 |
| 8-species Boltzmann | `boltzmann/solver.py` | Appendix B, Fig. 3 |
| Sommerfeld enhancement | `sommerfeld/` | Appendix C, Fig. 4 |
| Relic abundance | `relic/abundance.py` | Section 4.1 |
| Collider cross-sections | `signatures/collider.py` | Section 5.1, Table 4 |
| GW spectrum | `signatures/gravitational_waves.py` | Section 5.2 |
| Observational data | `data/fetcher.py` | Sections 4–5 |
| Validation suite | `data/validators.py` | All |

## Installation

### Option 1: Docker (fully reproducible)

```bash
git clone https://github.com/ahmed19999520-alt/dark-octet-dm
docker compose -f docker/docker-compose.yml up
```

Open `http://localhost:8888`.  
All notebooks, source code, and data are volume-mounted and editable live.

### Option 2: Local Python install

```bash
git clone https://github.com/ahmed19999520-alt/dark-octet-dm
pip install -e ".[dev]"
```

Requires Python >= 3.10.

## Notebooks

### AppendixA_Homotopy.ipynb

Step-by-step homotopy proof that π₂(SU(3)/[SO(3)×Z₂]) = ℤ.
Covers: covering space argument, long exact sequence reduction,
Hurewicz theorem application, BPS field equations, and topological charge integral Q = 1.

### AppendixB_Boltzmann.ipynb

Full derivation and numerical solution of the 8-species coupled Boltzmann
hierarchy with the dark Higgs triplet contribution. Includes: equilibrium yields,
effective σ_eff with co-annihilation, Griest-Seckel enhancement with g_eff = 5.09,
BDF ODE integration, freeze-out determination at x_f = 26.97, and Lee-Weinberg
relic abundance formula yielding Ω_DM h² = 0.1199.

### AppendixC_Sommerfeld.ipynb

Complete Sommerfeld enhancement calculation. Covers: dimensionless
Schrödinger equation for Yukawa potential, inward integration from
asymptotic plane wave, Coulomb analytic formula S_Coulomb(v), Yukawa
correction factor ≈ 0.52, and σ_T(v) across the full astrophysical velocity range.
